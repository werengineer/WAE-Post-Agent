# Using AI Tools as an Engineering Student Without Losing the Fundamentals

AI assistants can explain a datasheet, debug a script or sketch a design in seconds. The risk is that the tool does the thinking and you never build the skill. Here is a practical way to use it.

## Use it as a tutor, not a vending machine
Ask for explanations, then explain it back in your own words. If you can't, you haven't learned it yet.

## Try first, then ask
Spend 20 minutes on the problem. Then ask the tool where your reasoning went wrong, not for the final answer.

## Check everything you can check
- Do the units work out?
- Does the answer pass a rough estimate?
- Does the code run on a test case you wrote?
AI tools can be confidently wrong. Verification is an engineering skill in itself.

## Keep a "no-AI" hour
Once a week, solve something from scratch. Like gym sessions, the effort is the point.

## Be ready to explain your work
In an interview you may be asked why you chose a design. "The tool suggested it" is not an answer.

## Be honest about it
Follow your college's rules and say when AI helped in a project write-up.
