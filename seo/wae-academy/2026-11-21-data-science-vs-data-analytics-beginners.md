# Data science or data analytics? What a beginner should learn first

**The short answer:** start with data analytics skills. Learn SQL first, then Python, then statistics. Machine learning, which is the core of data science, comes after that. Most beginner guides agree on this order. You can choose "analyst" or "data scientist" as a job goal later, once you have worked with real data.

### Data analytics and data science in plain words

- **Data analytics** answers questions you already have, using data from the past. Example: "Which product sold the most last quarter, and in which city?" The usual tools are Excel, SQL, a dashboard tool and some Python.
- **Data science** goes further. It looks for patterns nobody asked about yet and builds models that predict things. Example: "Which customers are likely to leave next month?" It uses more Python, more statistics and machine learning.

The two overlap a lot. Many data scientists spend much of their time on analytics work, and every data scientist needs SQL and Python.

### What to learn first, in order

1. **Spreadsheets and basic maths.** Averages, percentages, tables and charts. You can do this in Excel or Google Sheets.
2. **SQL.** SQL is how you pull data out of a database. Several guides suggest starting here because the basics are quick to learn and you can answer real questions early.
3. **Python.** Learn the basics (variables, loops, functions), then the data libraries, mainly pandas for tables and a charting library.
4. **Statistics.** Distributions, sampling, correlation and testing an idea against data.
5. **Dashboards and storytelling.** Show your result in a way a manager can read in one minute.
6. **Machine learning.** Only after the steps above. Start with simple models, such as predicting a number or a yes/no outcome, and learn how to check if the model is any good.
7. **A project that uses all of it.** Pick a real data set, ask one clear question, and write up what you found.

How long does each step take? It depends on your time and practice. One guide estimates a few weeks for basic SQL and one to two months for basic Python syntax. Treat such numbers as rough.

### Which one should you start with?

- Choose **analytics first** if you are new to coding, come from a non-IT background, or want your first job sooner. The skills are also the base of data science, so nothing is wasted.
- Choose **data science first** only if you already program and are comfortable with maths. Even then, learn SQL early.
- Not sure? Do steps 1 to 3 above for a month. If you enjoy it, carry on. If you do not, you have lost little.

Note: no course can promise a job. Judge a course by what you will build, not by what it promises.

### How to practise without paying

- Write 20 small SQL queries on a free sample database.
- Take one public data set (for example, from a government open-data portal or a data-science competition site) and ask three questions about it.
- Put your notebooks and write-ups on GitHub. A project you can show is stronger than a certificate.

### Questions to ask before you join a data course

1. Is SQL taught, or does the course jump straight to machine learning?
2. How many projects will I build, and can I see examples from earlier batches?
3. Who teaches it, and have they worked with data in a job?
4. What are the entry requirements, fees, batch dates and timings? Get them in writing.
5. What does "placement support" mean exactly? Ask for the written terms.

## FAQ

**Is data analytics easier than data science?**
Usually yes for a beginner. Analytics needs SQL, spreadsheets, some Python and clear thinking. Data science adds statistics and machine learning on top.

**Should I learn SQL or Python first?**
Several guides suggest SQL first, especially for analytics roles, because the basics are quick to learn. Python comes next. If your goal is machine learning, you will spend most of your time in Python, and you can learn both in parallel sooner.

**Can I learn data science without a coding background?**
Yes, but plan for time. Start with spreadsheets and SQL, then learn basic Python step by step. A structured course with projects and a mentor can help.

**Do I need strong maths for data analytics?**
Basic maths is enough to start: percentages, averages and reading charts. Statistics matters more as you go deeper, and more still for data science.

**How long does it take to learn data analytics from scratch?**
It depends on your starting point and practice time. Course pages in Delhi list anything from about 30 hours to 11 months. WAE Academy's site states 3 to 6 months for its courses.

**Do I need a degree in computer science?**
Not always. Many guides say employers look at your skills and projects. Check the entry requirements of each course and employer.

**Does WAE Academy teach data science and analytics?**
