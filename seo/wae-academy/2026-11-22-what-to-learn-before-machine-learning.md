# What to learn before machine learning: a plain roadmap for beginners

**The short answer:** learn Python first. Then learn to work with data using NumPy and pandas. Add basic maths and statistics along the way. Then build one small project. Guides from Google and from course providers agree on Python and some maths. They differ on how much maths you need at the start, and this page explains why.

### Step 1: Python basics

Machine learning work is mostly done in Python. Learn the basics first: variables, lists, loops, functions and reading a file. You do not need advanced Python to begin. You need to be able to read a short script and change it.

### Step 2: Work with data (NumPy and pandas)

Google's Machine Learning Crash Course lists familiarity with NumPy and pandas as prework. In plain words:
- **NumPy** helps you work with numbers in bulk, such as lists of values.
- **pandas** helps you work with tables, like a spreadsheet inside Python. You load a table, clean it, filter it and summarise it.

Most of a real project is this step: getting the data into a clean shape before any model is built.

### Step 3: Basic maths and statistics

The topics most guides list are:
- **Algebra**, to read formulas.
- **Statistics and probability**, such as averages, spread, and how likely something is. They help you judge whether a prediction can be trusted.
- **Linear algebra**, which is about lists and tables of numbers. It becomes more useful as you go deeper.
- **Calculus**, which is optional at the start. It matters later for ideas such as how a model learns (gradients and backpropagation).

### How much maths do you really need?

Sources disagree, and the honest answer is "it depends on the course and the goal."
- Some beginner guides say high-school maths is enough to start, because libraries such as scikit-learn do much of the calculation for you.
- Google's crash course lists algebra, linear algebra and statistics, with calculus as optional.
- Some advanced programmes ask for calculus, linear algebra and Python before you join.

A sensible plan: start with school-level maths and statistics, build a project, and add linear algebra and calculus when you want to understand how the models work inside.

### Step 4: Your first small project

Pick a small table of data and ask one question. Example: predict whether a message is spam, or predict a number from a few columns. Clean the data with pandas, train a simple model with scikit-learn, and check how well it did. Write down what you did and what went wrong. A small finished project teaches more than another week of reading.

### Common mistakes to avoid

- Waiting to "finish the maths" before writing any code.
- Jumping into neural networks before you can handle a table of data.
- Copying a notebook without understanding each step.
- Skipping the check of how well your model works on data it has not seen.

### Questions to ask before you join an AI/ML course

1. Which skills does the course teach from zero, and which does it expect you to have?
2. How many projects will you build yourself?
3. Who teaches it, and can you speak to a mentor?
4. What is the full syllabus, and how long is it?
5. What are the fees and batch dates? Ask for them in writing.

## FAQ

**What should I learn before machine learning?**
Python first, then NumPy and pandas for working with data, then basic maths and statistics. After that, build one small project.

**Do I need to know Python before learning machine learning?**
For hands-on machine learning, yes, you need at least the basics. Python is the common language for it. Some conceptual AI courses need no coding, so check what the course teaches.

**How much maths do I need for machine learning?**
School-level maths is enough to start. Statistics and probability matter early. Linear algebra and calculus matter more as you go deeper.

**Is calculus required for machine learning?**
Not at the start. Google's crash course treats calculus as optional. It helps later, to understand how models learn.

**Can a beginner learn machine learning without a computer science degree?**
Many beginner courses teach the basics from scratch. Check the entry requirements of each course and employer.

**Should I learn data analytics before machine learning?**
It is a good route. Analytics teaches you SQL, tables and charts, which you use in machine learning too.
