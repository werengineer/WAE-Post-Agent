The Delhi page describes the course as end-to-end web engineering:

- **Front end:** modern client interfaces with React and Next.js.
- **Back end:** APIs with Node and Express, or with Java Spring.
- **Databases:** database design.
- **Cloud:** deploying your work to the cloud.
- **Live project:** a live microservices project.
